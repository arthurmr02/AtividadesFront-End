# Sonserina — Sob o Lago Negro

Landing page temática inspirada no universo de Harry Potter e na casa Sonserina. Projeto acadêmico desenvolvido para explorar vibecode, identidade visual e avaliação crítica de resultados gerados com auxílio de IA.

## Tecnologias
- React
- Vite
- CSS responsivo
- Lucide React para ícones
- Google Fonts: Cormorant Garamond e Inter

## Como executar localmente
1. Instale Node.js (versão LTS recomendada).
2. Abra um terminal nesta pasta.
3. Execute `npm install`.
4. Execute `npm run dev`.
5. Abra no navegador o endereço local informado pelo Vite.

Para verificar a compilação de produção, execute `npm run build`.

## Estrutura
- `src/main.jsx`: componentes e conteúdo da página.
- `src/styles.css`: identidade visual e responsividade.
- `docs/`: briefing, referência, pesquisas, prompts, decisões e validação.

## Observações
- A página é uma única rota com navegação por âncoras.
- As fotografias são carregadas de URLs externas do Unsplash; é necessária conexão com a internet para visualizá-las. A disponibilidade e a licença de cada imagem devem ser verificadas antes da entrega acadêmica.
- As informações canônicas e fontes visuais precisam ser verificadas e registradas antes da entrega final.
- O projeto é um trabalho de fã, sem fins comerciais, e não é afiliado aos titulares de Harry Potter.


## Documentação do processo
A pasta `docs/` contém o briefing, referência visual, pesquisas e fontes, identidade visual, histórico de prompts, decisões de design, checklist de testes e retrospectiva. Os testes técnicos estão explicitamente marcados como pendentes até serem executados no ambiente local.
